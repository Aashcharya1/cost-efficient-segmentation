## Recorded final benchmark

DUTS-TE, 5,019 images: mIoU **0.7083**, Boundary F1 **0.4726**, Q **0.6376**, mean single-thread CPU time **10.821 ms**, parameter file **499,643 bytes**, CES **0.6024**.

The root parameter filename is retained for compatibility. Despite `_fp16` in its name, it contains mixed-precision/packed storage and reconstructs a float32 CPU model. Do not replace it with an intermediate checkpoint from experiments or a training resume state.

## Final local checks

Run from the project root:

```powershell
python -m unittest discover -s tests -v
python verify_submission.py
python predict.py --image captured/original/body_wash_bottle.jpg --out report/check_mask.png
```

For the actual report figures, all six personal images are retained; none was selected out because of its score. Your source files are the received WhatsApp JPEGs, preserved unchanged. Camera originals were not supplied; provide them if the instructor requires the strict original-camera-file interpretation. Fine manually traced spokes, chair slats and fur edges remain approximate and should be reviewed before submission.

The only mandatory inputs to standalone inference are the code, installed dependencies, one input photo and `params/model_fp16.pt`. The full DUTS dataset and optional training cache are not needed for prediction.

## Rebuild the ZIP after changing a submission file

```powershell
python package_submission.py
```

Replace the root PDF first if you export a revised report, then rebuild and submit the new ZIP. Packaging refreshes the SHA-256 manifest. Do not edit measured numbers merely to match a new narrative. Re-evaluate the frozen model if parameters, inference code, images or masks change.

## What not to upload

The submission intentionally excludes the raw DUTS dataset/archives, approximately 2.6-GiB training cache, optimizer `resume.pt` files, temporary diagnostics, local environments and retired web images. These are not needed for the required deliverables; the dataset download and cache-preparation scripts are supplied.
